# Budget Analysis (Crypto Rock Index)

A Python-based financial budgeting and personal expense tracking tool designed to analyze monthly income, monitor expense ratios, and provide automated financial feedback.

## Features
- **Income & Expense Tracking:** Safely captures monthly cash flow and validates user input.
- **Spending Ratio Analysis:** Calculates savings and spending percentages relative to overall income.
- **Smart Feedback System:** Generates customized financial recommendations based on budget surpluses or deficits.

## Technologies Used
- Python (Core logic, exception handling, mathematical formatting)

## How to Run
1. Clone the repository.
2. Run the `main.py` file using any standard Python environment.
